👥 Workforce

Workforce is a full-stack application designed for managing employees and tasks in a company. The platform allows for the management of users, tasks, and roles, providing an organized and efficient system for managers and teams.


✨ Key Features

👤 Employee Management – ​​add, edit and delete

📝 Task Management – ​​create, update and select task status

🛠️ Role-based access – each user has access based on their role

📊 Comprehensive dashboard for managers and team

🖥️ Modern front-end built with React.js

🛠️ Technologies used

Frontend: React.js

Backend: Node.js with Express.js

Database: PostgreSQL for storing employee and task data

Deployment: Vercel (frontend) and hosted backend for full-stack deployment

🎯 Project Goal

This project demonstrates the skills in building a professional full-stack application, including:

employee and task management with different roles

modern and functional user interface

integration with PostgreSQL database for storing and processing real data.
